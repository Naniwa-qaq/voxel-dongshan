## 当前最有用的参考

1. **惠和堂俯瞰（16）与平面（17）**：已取得可读文件，可识别多路院落、天井和屋顶。俯瞰为3284×4925像素，平面为620×840像素；未见坐标、比例尺或尺寸链，适合相对布局和制图综合，不能当精确测绘成果。
2. **紫石街（04）与寒山港（02）**：可读街巷宽高感、连续墙面、跨街牌坊和水岸—民居关系。陆巷入口牌楼（01）是另一处入口形象，不能把它混作紫石街三座牌坊之一。
3. **春在楼（12）、轩辕宫（13）与惠和堂局部（05—08、18）**：用于保留楼廊围合、门楼、屋顶轮廓和院落留空；不要求复制雕刻与每个窗格。
4. **启园（09—11）与岱心湾桥（14）**：前者是园内池石/廊桥/照壁，后者明确展示太湖滨湖道路。不得把启园园池照片误作太湖实测岸线。
5. **楠木厅（15）为室内梁架图**，不用于推断整座外观。

## 用于本项目的取舍

当前目标是风格化、制图综合后的东山。普通民房可按街坊聚合，重复小建筑与低等级水段可删减；本图组用于定义少数特色POI的形体签名、院落空隙、地方材质和山湖水岸关系。没有足够证据时，保留类型符号，不补造真实院落、校园或港工布局。

本批图没有提供学校实景、完整港区平面、全域现状底图或最新建筑高度。古宅照片与园林图有选择性，不能外推为所有普通民房。
