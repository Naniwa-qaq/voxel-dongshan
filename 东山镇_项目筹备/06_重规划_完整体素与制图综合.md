# 东山镇重规划：完整体素、完整屋舍、制图综合

2026-10-20。当前为规划阶段，失败原型继续保持撤回状态。本文件是后续制作的主方案，与修订后的[表达规范](04_制图综合与表达规范.md)、[验收清单](03_数据验收清单.md)共同使用。

**先确定一栋房屋应达到的完成度，再决定保留多少栋、怎样组织街坊与全域。每一座入选屋舍都达到参考案例的近看精度。** 普通民居与地标共享构件质量标准，差别在形制与规模。

## 1. 本次固定的制作要求

| 对象 | 新基线 | 明确排除 |
|---|---|---|
| 每座入选屋舍 | 约0.2米局部构件网格；完整屋顶、正脊、檐口、墙体、门窗深度、山墙/封檐、台基及适用的院墙与台阶 | 仅地标精细、普通房只有墙盒加顶；放大模型后仍看不到构件 |
| 地形与岸坡 | 方格柱体的平顶面、竖向外露面与台阶轮廓，接地与岸线共同构造 | TIN斜三角面、低多边形山体、用格纹滤镜遮盖斜面 |
| 树木 | 体素主干、分枝、主次叶簇、冠缘起伏和枝叶空隙；树型可辨 | 多面体球冠、圆锥树、几根杆配一整块大冠；均匀撒绿色噪点 |
| 道路、桥、墙与护岸 | 连续可通达的方块构造、台阶边缘，桥与河岸衔接明确 | 漂浮细带、穿屋的道路、被粗格吞掉的水口 |
| 水与氛围 | 岸边采用一致格网边缘，水色/波纹保持离散节律；光雾服务已有形体 | 大斜水片披覆坡地；靠浓雾、俯瞰或压暗掩盖缺失构件 |

“完整体素”要求可见造型由方块、方阶与离散轮廓构成。连续面可以合并提交，内部渲染仍可使用共面三角形；这不会产生用户反对的不规则斜三角外观。无需为每个体素创建一个独立立方体对象。

## 2. 屋舍和树木怎样达到参考程度

### 屋舍：先做完整资产，再做变体

- 屋顶逐层收分，具有檐板、可读的出檐、正脊和符合类型的山墙；适用时增加封檐、腰檐或廊下结构。瓦缝纹理补充几何，不替代层叠屋面。
- 墙面有厚度，门窗有框、凹入与必要透空；院门、围墙、天井、台阶和接地共同形成空间。不能在一个实心盒子上画黑窗就算完成。
- 普通住宅也具备完整正、背、侧面及檐下。未掌握某栋实测立面时使用有当地依据的类型化资产，记录其设计身份。
- 改开间、宽深或层数时重新组合构件；不通过非均匀缩放把门窗、墙厚和瓦层一起拉扯。
- 建筑依其街向设置局部构件坐标，所有构件在局部细格上对齐；地形采用统一世界方格，建筑与地形间用体素台基、岸阶衔接。
- 借鉴参考的构件密度与构造方法。东山普通宅、院落、现代住宅及校舍分别建立形制，不能把原作的徽式山墙、吊脚楼、宫殿和巨瀑统一套进东山。

### 树木：减少重复株数，保留完整树型

树冠由多层大小不同、相互错落的小盒簇形成，主枝之间留空；树干粗细递变，枝条通过短方柱或阶梯段连接。至少分别研究阔叶、临水和园林/果树意向的冠形，按资料决定实际采用哪些类型。茶果林的片区分布、实际树种与造型设计分别记录。

远景可合并被遮挡的枝叶内面，但保留林缘、冠层层次和孔隙；进入可近看的范围前恢复完整树。房树同场验收，不能再用大冠盖过房屋来制造“丰富”。

参考依据：[原作街区实拍](../云山巨城_学习档案/images/07-street-afternoon.jpg)、[台城实拍](../云山巨城_学习档案/images/08-terraces-afternoon.jpg)，以及源码的屋顶函数约980行、房屋约1142行、树木约2443行。0.2米是参考构件步长，不是东山测绘精度。

## 3. 制图综合怎样缩减内容

保留三套记录：**源地理坐标 → 综合设计坐标 → 渲染坐标**。源坐标保存真实位置与证据；综合设计坐标处理对象选择、组团和必要的空间压缩；渲染坐标只处理坐标轴、局部原点和显示单位。

| 操作 | 实际处理方式 | 必须保住的关系 |
|---|---|---|
| 选择 | 减少同质重复民房、支沟及附属设施；优先保临街、临水、组团边缘和特色对象 | 聚落类型、主街/港道、院落序列、关键桥头和水口 |
| 聚合 | 把来源房群概括为若干**完整房屋＋院落＋巷道**组成的组团 | 街坊边界、连续街墙、疏密梯度、院落与通路留空 |
| 空间压缩 | 缩短重复街段、同质过渡地带和无辨识作用的间隔，联动重排道路、岸线与房群 | 半岛主要长宽关系、山湖层次、沿街/沿岸顺序、岛陆分离与主要方向 |
| 局部夸张 | 为可读性略加宽关键巷道、院门或窄港，分别记录显示尺寸 | 不堵水口、不切断桥路、不把小亭放成半个村 |
| 必要移位 | 在同一街坊与同一岸侧内消除冲突，重新检查入口与占用范围 | 不跨必保道路、水道、校园或重点古建边界 |

例：一段由数十栋相似住宅构成的街区，可以只保留若干完整宅院，缩短重复街段，维持临街一排、后排院落与通湖巷的层次。每一座入选宅院仍有完整构件。不能换成一条巨型屋顶，也不能把全部房屋和门窗一起缩小。

空间压缩属于明确的设计变形，会改变局部距离和面积。必须保存源/设计对照图与操作记录，核查山脊—坡脚—村落—湖岸的层次、地标邻接及必保网络。出现翻折、改岸、断路或比例失衡时，应扩大设计空间，而非继续硬塞。

不预设全镇压成1.28公里，也不先规定全镇保留多少栋或统一删掉多少比例。用完整房院的占地、街巷和水域留白推导片区尺寸，再推导全域尺寸。

## 4. 场景范围与观看尺度

推荐采用**一个经过制图综合的连续体素景观，加全域导航总图**。全域负责认识东山与三山岛；主要体验是可进入的街区、岸边和山前聚落。所有入选屋舍都拥有可近看的完整资产，全景中的小投影不构成降低资产标准的理由。

先做陆巷代表片区，覆盖相连的住宅、街巷、坡地和岸边关系。以已核实的陆巷村点及现有路水/足迹确定样区；村点不代替古村边界。惠和堂、紫石街、寒山港的具体落位仍需核对，已有图文可用于独立形制研究，不能用附近任意院落或水沟冒名。

首轮观看条件统一记录有效画布、FOV、相机位置、光照和雾。候选条件为1440×1000、DPR=1、垂直FOV=45°，通过样件后固定：

| 视角 | 验收用途 | 画面要求 |
|---|---|---|
| 单体近景：四向/斜俯/檐下 | 校准完整房屋与完整树的工艺标准 | 房宽先试350–750像素，并校核0.2米关键边在有利投影下至少约4像素；与参考同等屏幕占比对照 |
| 沿街与临水中近景 | 检查房屋结构、院落、街水宽高及房树关系 | 主体普通房屋首轮按约80–150像素宽校准整体识别；门窗深度与构件细度另由单体近景验收 |
| 街坊斜俯视 | 检查密度、屋顶节奏、天井和巷道负空间 | 组团由多座可辨完整屋舍构成，古村/现代镇区有差别 |
| 全域总图 | 检查山湖、主要聚落、三山岛与总体主次 | 保持识别与导航作用；不代替单体、沿街和片区验收 |

## 5. 地形与性能的实现边界

约30米源DSM保留原有样本；先重建宏观高度场，再生成方阶显示。可接近地段以1米、普通地段以2米柱格作为首轮候选，垂直阶级另行校准；关键岸线可局部细分。显示加密不能冒充新增实测信息。

地面与水面共用同一版岸线；每柱只输出顶面和外露竖面。台基、道路、树根使用同一显示地表查询。禁止再次用100米水陆掩膜侵蚀岛缘和港口。

性能优化依次使用：隐藏面剔除与合面、完整资产复用、空间分块、视锥剔除、分块驻留和预取、按屏幕尺寸选择LOD。LOD只能合并已经不可辨的细节，进入近看范围前恢复完整构件和透空，保持对象身份、轮廓和位置。普通房不能长期只持有一份简盒资产，树不能退成多面体球冠。

模型精度与调度成本分别验收，不预先承诺未经测量的全镇帧率或内存。各阶段记录生成时间、驻留、绘制和固定镜头表现。

技术上优先提取参考案例的盒构件、层叠屋顶、方阶地形、近远资产和分块方法，适配东山的建筑类型与街向。渲染后端负责提交这些网格，不能再用通用低多边形几何代替构造；是否复用具体引擎代码由样件与运行测量确定。

## 6. 制作顺序与完成条件

| 阶段 | 具体交付 | 完成条件 |
|---|---|---|
| A：资产基准 | 沿街宅、院落宅、现代房/校舍等普通建筑样件；完整树型；一段坡地与岸阶 | 灰模与正常日光下对照参考；每栋房和每株树的轮廓、构件与房树尺度成立 |
| B：制图综合设计 | 样区源/设计双图、必保关系表、删选与移位记录、完整资产摆放图 | 房院、街水关系保留；密度在综合后的设计空间内合理，不能仅用来源计数守恒作判断 |
| C：陆巷连续样区 | 可进入的完整体素片区，固定单体/沿街/临水/斜俯机位 | 无TIN外观、粗树、简盒房、漂浮物、堵口或跨街误归属；缺资料的地标状态明确 |
| D：扩展与运行 | 连续扩展其他村落、镇区和山湖；分块、LOD、导航与光照 | 各片区保持同一工艺；切换不漂移、不开裂、不缺半栋；在记录的设备与画布实测性能 |

先完成A—C再铺开全域。前期不制作大范围壳体来代替完整样区。四类检查分别记录：资料/坐标、制图关系、资产与视觉、运行性能；任一类检查通过都不能代替另一类。

下一阶段资料补充集中在：普通现状屋舍的正侧面、屋顶和入口细部；庭院/路旁树及茶果意向的冠形；陆巷特色街巷、古宅和港道的可靠落位。它们用于支撑完整类型和必要空间关系，不以全镇逐屋精测作为前提。
