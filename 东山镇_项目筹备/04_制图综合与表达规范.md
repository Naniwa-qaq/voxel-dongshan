# 东山镇：制图综合与三维表达规范

修订日期：2026-10-20。依据用户对制图综合、每个入选屋舍达到参考精度及完整体素风格的要求修订。失败首版已撤回；本文件与[重规划主方案](06_重规划_完整体素与制图综合.md)共同作为现行制作规范。

## 1. 作品目标

制作以真实地理为骨架、经过制图综合的东山完整体素景观。山湖形态、聚落分布、主要水路与特色节点提供地方辨识；大量重复住宅、次要水道与微小设施允许选择、组团或省略。每座入选屋舍仍制作参考案例级别的完整近景构件，普通民居与重点建筑共享这一标准。

前期资料方案曾对逐栋轮廓和精确尺寸要求偏重，现予调整。衡量内容是否值得保留，应先看它对目标画面的地理理解、文化辨识和视觉组织有何作用。

专业制图综合包括选择、简化、合并、适度夸张及必要移位；它需要同时考虑道路、水体与聚落等要素的关系。官方多尺度制图文档明确说明了这些原则。[Esri多尺度制图说明](https://doc.esri.com/en/arcgis-pro/latest/help/mapping/map-authoring/author-a-multiscaled-map.html)。本项目借鉴其理念，不限定采用某款GIS软件，也不在本轮运行工具。

## 2. 分开处理三种“规模”

| 问题 | 对应手段 |
| --- | --- |
| 地理范围太大、不便观看 | 在必保地理关系下压缩重复街段和同质过渡空间，以完整房院推导设计范围；全域导航与连续片区分工 |
| 内容太密、重复对象太多 | 制图综合：民房分组、次要网络抽稀、POI类型化、重要对象优先 |
| 显存、文件或绘制开销过大 | 分块、几何LOD、实例复用、细节/阴影/分辨率分级；后续按实际设备验证 |

源地理坐标保留真实位置，内容综合设计坐标记录删选、组团、必要移位与空间压缩，渲染坐标处理局部原点和单位换算。设计变形必须检查山湖层次、沿线顺序、邻接与路水连通，不用一个全局缩放系数同时决定房屋、地形和镜头。局部夸张有独立参数，不改写原始数据。

所有入选屋舍采用约0.2米局部构件网格，具有完整屋顶、檐口、门窗、墙厚、台基及适用的院落构造。地形使用方格柱体顶面与外露阶面，树木使用有枝干、分层叶簇与透空的体素资产。禁止TIN外观与多面体球冠。通过外露面合并、完整资产复用、分块驻留和LOD节省成本，无需存储全镇0.2米稠密体积数组。

## 3. 要素取舍矩阵

| 对象 | 优先保留 | 可以简化、合并或省略 | 综合限制 |
| --- | --- | --- | --- |
| 半岛与太湖 | 整体形状、主要岸线转折、山湖关系、重要水口 | 微小岸线锯齿、重复护岸设施 | 保住地标附近和港岸处的关键几何关系 |
| 山体 | 主要山脊、峰谷轮廓、山前聚落位置与高低次序 | 高频地形噪声、细沟、微地形 | 允许轻度起伏强化，保持山地/平地与相对高度关系 |
| 普通住宅 | 聚落位置、沿街/临水走向、疏密高低，以及每座入选屋舍的完整构件 | 选择省略重复民房，组织为若干完整房院组团；减少附房杂物 | 不以一条大屋顶替代整片，不跨必保道路、水道或重要POI |
| 主街与道路 | 片区连接、进村方向、地标入口、重要桥头 | 次要尽端路、重复支路和不可读细弯 | 先保连续路径，再做简化；加宽后复查与房屋水体冲突 |
| 河道与港道 | 入湖口、特色港道、必要连通链、重要桥下水段 | 无识别作用的低重要性支沟、重复小水面 | 短、窄或行政等级低不等于可以删除；先分析作用与连通 |
| 特色古建 | 总体朝向、长宽关系、主轴、院落与屋顶层级 | 每间房屋、窗格、雕刻和小构件 | 重要古建不并入普通民房组，不统一套成同一座塔或殿 |
| 学校 | 校园位置与占地量级、教学体量组、已确认的留空空间 | 重复教学楼、内部支路及附属设施 | 操场、看台等仅按资料保留，未知布局不套标准校园 |
| 湖港/渡口POI | 水陆接口、港道或港池入口、主要码头方向 | 逐船、逐桩、泊位与设备 | 先分清本地“港”的对象类型，不把港道一律做成工业港池 |
| 茶果林 | 片区范围、与山村关系、林缘及有枝干/叶簇/透空的体素树型 | 减少重复树、茶垄与田埂，远景合并不可辨内面 | 不做均匀松林，不以单块大冠或多面体树替代完整树型 |

建筑群合并时，道路和河流应作为屏障；专业聚合工具也明确采用这类跨要素约束，而非只按距离合并。[多边形聚合说明](https://doc.esri.com/en/arcgis-pro/latest/tool-reference/cartography/aggregate-polygons.html)

## 4. 民房综合方法

1. 先根据主路、水系、地形和重要POI划分街坊/聚落组。
2. 为组团记录大致边界、重心、主要方向、疏密、高度范围和建筑类型。
3. 用若干完整屋舍、院落、围墙与巷道组成的组团表达重复住宅；数量可以减少，构件精度不降低，密集古村与疏散村落仍应不同。
4. 优先保留临街、临水和轮廓边缘的代表房屋；内部重复小屋可以合并。
5. 预留主街、特色巷道、关键院落和水道空隙，不让大体块填满所有空间。

例如，一片数十栋重复住宅可概括为数个建筑群，每群保留少量完整房屋与真实可读的院落、通路空隙；必要时缩短重复街段，维持沿街次序与临水关系。组团可以代表多个来源对象，但不能变成巨型屋顶。削减比例需在固定镜头与设计空间中比较确定，不规定全镇统一删掉多少。

完整类型资产可以复用，改变宽深、开间或层数时重新生成构件，不非均匀拉伸门窗与瓦层。民房的选择应稳定，不随每帧随机替换，也不因帧率下降临时删掉地理对象。

## 5. 河网与POI的例外规则

### 河网

先锁定要保留的湖港、水口与关键桥，再找维持其关系所需的水段。其余支沟按地方意义、画面密度和目标尺度选择。窄水面可以从面状水体转换为细带或中心线表达，但入湖联系与桥河关系必须继续成立。

不能只按单段长度删除，因为一条主要水道可能被源数据分成多段。不能只按自然河流级序筛选人工港道，也不能把小而有文化意义的水道自动降级。道路抽稀中的层级、密度与连通性共同约束可作方法参考；河网仍需按自身语义检查。[网络抽稀说明](https://doc.esri.com/en/arcgis-pro/latest/tool-reference/cartography/thin-road-network.html)

### POI

POI可保留可靠点位或区域锚点，另用概括的显示几何表达。先写下其最重要的两三项识别特征，再决定哪些细节省略；此为设计建议，不是实际对象必须具备的通用公式。

- **惠和堂候选：**保留并行院落带、前后多进节奏、天井空隙与围墙/入口；选择表达的房体均有完整构件，不用连片大屋顶填院。远景可合并不可辨的细面，院落负空间始终保留。当地布局参考来自[园林局介绍](https://ylj.suzhou.gov.cn/szsylj/ylml/201912/d3d1a3a77c9d40acaa97f641111d8481.shtml)，具体地理落位仍需核对。
- **学校类别：**用主要教学楼组、校园边界与真实可确认的空地表现。没有可靠平面时用类别标记或简略体量，不凭空造运动场。
- **湖港类别：**用清楚的水口、岸线缺口、港道/港池与主要码头方向表现，省略大部分小设施。

地标可为可读性小幅放大某个特征，如门、檐口或院落间隙。优先调整局部特征，不把整个建筑无限放大。确需移位时保持所属岸侧、街侧与出入口关系，并记录原位置和显示位置。

## 6. 大致比例的约束

| 层次 | 约束方式 |
| --- | --- |
| 全域 | 半岛长宽、主要山体与湖岸关系、聚落与景点的分布次序保持可信 |
| 片区 | 保留大中小占地层级、街坊方向、密度梯度与主要水路走向 |
| 单体 | 保留主要长宽比、高度排序、院落/屋顶组织；雕饰和开间允许压缩 |
| 局部夸张 | 分别记录道路加宽、细部放大、高程表现与必要移位；超出可读性需要时重新审视 |

避免小亭变成半个村、学校与普通民房同大、港池覆盖整个湖湾。适度简化也不能把现代镇区统一变成古村，或把现实东山改造成原作的巨瀑悬崖山城。

## 7. 三档观看层级

| 层级 | 应看到什么 | 不要求恢复什么 |
| --- | --- | --- |
| 半岛全景 | 山湖轮廓、聚落块、主路与主要POI | 每栋民房、细河、窗格 |
| 片区观景 | 建筑群、代表屋顶、关键街巷/港道、POI轮廓 | 全量普通房屋与设施 |
| 入选对象近看 | 每座入选普通房与重点建筑的屋面、门窗、檐下、台基及适用的院落；树干分枝与叶簇 | 被主动省略的现实对象、无资料室内与逐栋实测复制 |

内容选择与资产完成度分开：靠近时不恢复已省略的现实对象，但必须能看到每个入选对象的完整资产。不能通过限制普通房的接近距离掩盖低精度模型。

同一对象的LOD保持相同身份、轮廓与位置，不重复绘制。进入细节可辨范围前恢复完整资产。性能优化先做外露面合并、资产复用、分块与剔除，再调远距阴影和渲染分辨率；不降低近景资产基线或临时改变对象取舍。

## 8. 资料需求与工作顺序的变化

最低资料需求调整为：区域高程、主要岸线/道路、水系与聚落范围、特色对象清单、少量能支持当地类型的图文。逐栋建筑数据有价值时可用作聚合输入或统计参考，但缺少全量屋顶、背面和精确高度不再阻塞首版。

先完成参考级普通房、树木与方阶地形样件，固定观看条件，再设计片区的必保关系、对象密度和取舍。构件格距、显示格距与地理实测精度分别记录；容差由样区比较确定，不预设全镇统一删减比例或固定建筑总数。

进入实现前，应先完成一张“对象—作用—保留特征—允许综合—不可破坏关系”的表。验收转向地域骨架、聚落纹理、POI辨识、保留网络连通性、相对比例和多尺度稳定，详见[修订验收清单](03_数据验收清单.md)。
