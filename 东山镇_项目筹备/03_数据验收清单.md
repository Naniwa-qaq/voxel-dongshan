# 东山镇概括表达：资料与作品验收清单

修订日期：2026-10-20。按完整体素与每个入选屋舍达到参考精度的要求修订。源数据已采集核验，失败首版已撤回；本表为重规划后的验收要求，不表示已有新版通过。

本表同时检验完整体素的资产质量，以及制图综合后东山的主要关系与特色。减少重复对象不降低入选屋舍的完成度；不要求逐栋复制现实中的全部建筑。

## 1. 资料记录仍需保留

| 维度 | 记录内容 |
| --- | --- |
| 来源 | 提供方、原始链接、版本、许可与署名 |
| 时空基准 | 覆盖、拍摄/测量日期、水平坐标、高程基准与单位 |
| 资料质量 | 分辨率/比例尺、已知缺陷、是否已实际获取；加载失败不算无数据 |
| 证据依据 | 地理数据、图文判断、程序估算或未知 |
| 表达处理 | 依源保留、选择省略、几何简化、群组合并、适度夸张、必要移位 |
| 对应关系 | 综合对象对应的真实对象或组团；无逐栋对应的建筑组应明确记录 |

证据和表达分开。例如，“来自可靠底图、主动合并的民房组”与“缺少资料、估算的建筑”不是同一种情况。

## 2. 核心验收

| 验收面 | 检查方法 | 不通过的典型表现 |
| --- | --- | --- |
| 完整体素造型 | 近景检查地形顶面/竖向阶面、建筑构件、树与岸路轮廓 | TIN斜三角山体、多面体球冠、光滑低模加像素纹理 |
| 每栋入选屋舍 | 检查普通房与地标的完整近景资产：约0.2米局部构件、层叠屋顶、脊檐、墙厚、门窗深度及适用院落 | 只给地标精细资产；普通房近看仍是墙盒加顶；门窗与瓦层被实例缩放拉扯 |
| 树木构造 | 四向、冠下和房树同场，检查主干/分枝、层叠叶簇、冠缘凹凸与透空 | 几根杆顶一个粗树冠，树形与房屋没有合理尺度关系 |
| 地域骨架 | 先选一组山体、岸线转折、聚落与地标锚点，比较成品的大形与相对位置 | 半岛形状失真，地标被搬到水岸另一侧，山前聚落变成山顶聚落 |
| 聚落纹理 | 比较主要方向、疏密、高低和连续屋顶节奏，区别古村、普通村落与现代镇区 | 随机删房后所有村落都变成均匀散点，或把全镇做成同一种古建群 |
| 分组边界 | 检查完整房院组团的同侧归属、实际占用范围和入口，逐一核对移位 | 最近空格搜索跨过街水；大屋顶填掉主街、院落或关键港道 |
| 路径骨架 | 检查保留的主路、进村路、地标入口与关键桥接关系 | 主要路径断开，路穿屋，桥失去应有的跨越对象 |
| 水系骨架 | 检查主湖面、关键入湖口、港道和保留水段是否连通 | 港池封闭、保留河段悬空、删短段切断主水道 |
| POI辨识 | 每个重点POI预先写明关键轮廓和空间组织，按目标视角检查是否可读 | 古宅只剩与普通住宅无差别的盒子，学校或湖港套用未经证实的标准布局 |
| 相对比例与密度 | 分别记录源面积、设计街坊面积和建筑占地；在设计空间比较疏密、高低、长宽关系 | 机械缩放房屋；减少数量同时无意稀释聚落；用来源计数守恒代替密度验收 |
| 多尺度稳定 | 检查全域、片区、所有入选屋舍/树的连续接近与LOD切换 | 重影、漂移、身份改变；靠近仍缺完整构件；通过禁止普通房近看掩盖粗模 |
| 可追溯 | 能查到哪些对象被合并、省略或夸张，估计属性有标记 | 将未显示解释为现实不存在，将表达高度写成实测高度 |

主动删去重复民房或次要河道属于设计取舍，不记作数据漏检；来源本身遗漏关键聚落或入湖口仍应记作资料缺口。

单体与街区使用不同验收机位：单体近景首轮试350–750像素房宽，校核0.2米关键构件边的有利投影至少约4像素；沿街中近景首轮按80–150像素房宽检查总体结构和空间关系。固定有效画布、FOV、光照与雾，并同参考作等屏幕占比比较；这些是待样件校准的设计条件，不是已验证指标。

资料/坐标、制图关系、资产与视觉、运行性能分别给出结果。数组、SHA、ID、计数或脚本无错误，只能证明相应结构或运行项，不能代替视觉验收。

## 3. POI按尺度要求资料

| 对象 | 首版足够的依据 | 可后补的内容 |
| --- | --- | --- |
| 普通民房组 | 聚落范围、主街方向、疏密和当地屋顶/立面参考，能支持完整类型化房院 | 逐栋实测、未知背面的实测资料与室内；完整资产本身仍需制作所有可见面 |
| 惠和堂等特色古宅 | 位置、大致占地与朝向、院落带/天井和主要屋顶关系 | 全部房间、精确开间、雕刻、家具及完整背面 |
| 学校 | 校园位置/范围、主楼组和已确认的主要空地 | 重复教学楼、附属设施；未知操场不凭空添加 |
| 湖港/渡口 | 先辨明港道、港池或渡口，保留岸线接口、入口及主要方向 | 泊位、船只、栏杆、逐根桩与设备 |
| 只有点位的POI | 类别、名称与可靠位置 | 暂用类别符号或概括标记；不捏造详细平面 |

## 4. 源数据诊断：可选，不作为作品逐栋准入门槛

需要确定某来源是否适合提取聚落与建筑统计时，可以检查局部遗漏、误检、粘连、来源日期与高度标签。优先问它是否能支持聚落边界、主要走向、密度等级和特色对象，而非要求达到统一的90%逐栋匹配。

出现系统坐标偏移、关键锚点缺失或水路关系明显错误时继续补资料；普通住宅缺少背面、精确高度或逐栋数量，不阻塞概括小样。

## 5. 开始概括小样的最低成果

- [ ] 普通屋舍、院落、现代房/校舍等完整资产样件与参考同屏对照，构件质量通过。
- [ ] 完整体素树型、方阶坡地和岸阶样件通过，无TIN和粗多面体树。
- [ ] 区域山湖骨架与主要聚落有足够依据。
- [ ] 重要对象清单及必保空间关系已列明。
- [ ] 已有民房聚合、水系取舍、POI轮廓与相对比例方案。
- [ ] 少量地方图文能支撑建筑与茶果林的类型特征。
- [ ] 已固定单体近景、沿街、临水和斜俯机位；所有入选屋舍拥有可接近的完整资产。
- [ ] 资料来源、使用方式、推断与概括处理可以追溯。

先通过资产样件和片区关系验收，再制作连续代表样区，最后扩展全域。后续优先补会改变核心关系与辨识度的资料；细显示网格和高完成度模型不得被记录为新增实测精度。制作顺序详见[重规划主方案](06_重规划_完整体素与制图综合.md)。
