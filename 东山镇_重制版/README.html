轮廓变化与构件尺度

普通屋舍分为传统民居、窄深屋、相连低排屋、L 形侧院、木门作坊、前廊现状民房、现代平顶房七类，另有完整院落组。变化落到平面、主脊方向、房前空地、体量高低和疏密不同的门窗上。按街段、宽深与院落从属选形，保留相连的街村关系。

逐层瓦顶、正脊、檐板、椽、墙厚与门窗进深继续使用 0.2 米构件网格。教学楼使用开放外廊、栏杆、双折楼梯和平顶；园林使用楼厅、跑马廊、池石与曲桥。树木保留连续枝干、细叶簇和透空，地表继续采用水平顶面与竖直侧面的方阶构造。

东山中学：教学组团与运动留空

以 OSM 校区 way/1101928342 和 Overture 源足迹为依据，地理锚点为 120.3967343, 31.0870303。场景有 8 个设施项：教学翼、校园公共楼与校门，配以田径场、球场和活动空间。教学翼采用三层外廊类型；分栋功能、具体窗位和层数尚未逐栋核定。

学校介绍与市公共资源交易中心改造招标提供身份和用地资料。运动区 78 × 156 米属于综合图形尺度；布局检查中，主楼误相交、道路穿主楼与运动场越界面积均为 0。

春在楼宅园：三进楼厅与小北园

地理锚点为 120.3997982, 31.0810719。OSM way/1332791315 是园区面，用于场地和位置约束。苏州市园林和绿化管理局的园林历史支持坐西朝东、前中后楼与厢楼相接、宅北置园、池石回廊曲桥的空间语汇。

当前有 10 个建筑设施项与 3 组叠石，包含三进楼厅、双层跑马廊和小北园。楼间距、池形、路径、园亭、树位与细部为形制综合。主宅楼厅没有冒用未命名足迹当作准确楼名。苏州地方志与市政府地名保护名录补充春在楼、雕花楼身份依据。
