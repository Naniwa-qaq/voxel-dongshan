# 东山 · 山湖之间

更新日期：**2026-10-23**。

当前应用把 **陆巷街村、东山中学与春在楼宅园放进同一张连续地图**，共享 world、地表和道路网络。打开时先显示全图总览；三处内容同时驻留，上方地点按钮只移动相机。可以沿路自由平移，从陆巷穿过山前地带到中学与宅园。

双击 [index.html](index.html) 即可离线打开，无需联网、地图密钥或构建工具。[中文阅读版](README.html) 记录统一地图的数据组织，并读取房屋与设施模块的类型统计。一个院落项可以由多栋房屋组成。

## 2026-10-23：地理对照与生态地被

场景新增“地理对照”入口，以北向上、等比例的源 UTM 锚点图，与当前制图位置并排比较。学校与春在楼园区的真实锚点直线距离约 **722.66 米**，当前图距 **405.62 模型米**；非等比分段压缩还使该方向偏转约 **5.32°**。春在楼坐标是 OSM 园区质心，不能替代主楼中心、门口或实测总平面。详见[地理核查](../work/地理核查_2026-10-23.md)与[可重建审计](data/geographic-audit.json)。

对照清单突出当前图幅内已具源位置、尚未具名建模的莫厘中学、莫厘实验小学、东山首末站、法海寺及莫厘峰观景亭，并区分缺少精确落位的陆巷文化场所与图幅外的紫金庵。清单属于覆盖审计，未把普通屋舍重新命名为这些场所。

地表使用既有 WorldCover 2021 覆被与过滤 DSM 坡度，经统一坐标逆变换形成生态参考。显示掩膜间距 10 米，边缘柔化后驱动连续地色；近处以实体方块草簇、蕨、莎草、灌木和落叶呈现高度与纹理。候选位置受水体、沟渠、道路、房院、围墙、硬地和运动场共同排除；冠下减少草坪，湿润低岸提高莎草概率，陡坡降低密度。10 米是显示域采样，源覆被 10 米、源 DSM 约 30 米，不表示新增测量精度。

树形新增香樟、常绿阔叶、落叶阔叶、枇杷、杨梅与水杉类型，与原有松、柳和竹丛共同分配。既有陆巷低地村旁设计树位的一部分采用枇杷、杨梅形态，森林覆盖类不会直接转换为“实测果园”。树种、树位、草簇和生态阈值均是地域资料支持的美术推断；地域植被依据见[莫厘峰官方现场报道](https://www.suzhou.gov.cn/szsrmzf/szyw/202510/f6ddb7f4edc749d18c8c86ba9cebdd81.shtml)与[资产验证及出处](qa/ecology-assets.json)。

生成：`scripts/build_ecology_mask.py`（既有 GDAL/NumPy/SciPy 环境）、`node scripts/build_geographic_audit.cjs`。验证：`node scripts/verify_ecology_assets.cjs`、`node scripts/verify_ecology_runtime.cjs`。源数据保持只读；本轮前场景脚本和界面备份在 `_回滚归档/2026-10-23_生态地理核查前/`。

## 这次改变了什么

针对截图中的大色板、屋下底盘、湖边空白回环和重复屋型，本轮调整了内容与地表组织：

- 去掉房屋平整范围与街坊范围的统一铺色。房基约束只参与地坪衔接；可见铺地由道路、门阶、真实用途的院地和场地决定。草地改为连续、细小的色差。
- 去掉三个低等级 service 回环展示段及仅连接它们的两条设计步巷；主路 11 段全部保留。道路按等级区分灰路、旧石、土石小径，避免等宽亮带。
- 核查三处河道上游端，发现源 OSM 线本身在此结束，几何完整。保留源中心线，在原线内渐窄并加低岸草；去掉样区南缘裁切残水段。上游连接、暗涵或塘面未取得证据，未新增连接水段。
- 把普通屋舍分为传统民居、窄深屋、相连低排屋、L 形侧院、木门作坊、前廊现状民房、现代平顶房七类，并保留完整院落组。按街段、宽深、院落从属选形，改变平面、主脊方向、体块高低和门窗节奏。

建筑继续以 **0.2 米构件网格**搭建，瓦层、正脊、檐板与椽、墙厚、洞口和内退格栅分别成形。新教学楼采用开放外廊、栏杆、双折楼梯与平顶；园林增加楼厅、跑马廊、池石和曲桥。树木保留连续干枝与透空细叶簇。

地表、屋舍、树木都以水平顶面、竖直侧面及阶梯轮廓组织，不再使用不规则三角网山坡或多面球树冠。

## 地理数据如何变成设计

**真实源数据 → 非均匀锚点映射 → 完整房院重新构造。**

陆巷源数据提供位置、足迹、路水关系与宏观地势。制图综合先按道路和水道分组，选取代表房院，归并同组重复内容；再对地理锚点和网络做单调的分段距离调整。门窗、层高和 0.2 米网格在设计位置重新构造。本轮建筑类型分配是设计表达，不能从初版足迹对照图推断新增立面已逐栋测量。

统一地图以同一个 **源地理坐标 G → 制图坐标 C** 映射衔接岸线、山势、源道路和三个内容区。已制作的房屋组团只作刚性平移，建筑尺寸与构件精度保持不变。北侧宏观地形读取源 DEM，跨区道路依据实际 OSM 路径进入同一网络；综合后的距离、道路宽度与显示地形属于地图表达。

学校、宅园周边和连接村路另从源建筑足迹选取街旁民居，按源街段与同侧关系形成镇村肌理。立面和层数仍为类型设计；筛选依据、原始锚点和保留对象见 [镇区肌理检查](data/town-context-qa.json)。阅读版的全图总数在加载 `town-context.js` 后统计。

初版源—设计关系保留在 [历史对照图](data/source-design-comparison.html)、[基础设计数据](data/design.json) 和 [分组记录](data/cartographic-groups.json)。本轮应查看 [统一地图数据](data/unified-map.json)、[统一坐标与路径检查](data/unified-map-qa.json)、[景观修订审计](data/landscape-revision-audit.json)、[设施布局检查](data/districts/layout-qa.json)、[源文件与静态链接审计](qa/unified-integrity.json) 及 [统一地图运行检查](qa/unified-runtime.json)。旧 [runtime.json](qa/runtime.json) 保留作历史记录。

普通立面、层数、树形及树位属于本地形态支持的类型设计。惠和堂、紫石街、寒山港尚未取得可靠的单体定位，场景没有把这些名字赋给任意房院、街巷或水道。

Copernicus GLO-30 的源 DSM 约为 **30 米**分辨率，用于宏观山势；陆巷近处采用 **1 米显示方格**、共享阶地与局部房基衔接。插值加密未新增实测精度。设施内部地坪参与统一地表衔接；局部整平不代表院内高差经过测量。

## 两个设施片区的依据

**东山中学**使用 OSM 校区 `way/1101928342` 与 Overture 源足迹，锚点为 `[120.3967343, 31.0870303]`。片区有 8 个设施项：5 个教学翼、2 个公共楼、1 个校门，并有田径场、球场和活动场地。教学翼按三层外廊类型搭建；楼栋具体功能与立面尚未逐栋核定。[学校介绍](https://dszx.wxedu.net/xxgk/xxjs1/content_250433)与[市公共资源交易中心改造招标](https://ggzy.suzhou.gov.cn/jyxx/003001/003001001/20260601/d63e67fd-aa44-4d19-8141-44b8d9ec1a0a.html)支持学校身份和用地资料；78 × 156 米运动区是制图综合尺度。详见 [校区数据](data/districts/dongshan-school.json)与[布局图](data/districts/dongshan-school-design-plan.png)。

**春在楼（雕花楼）宅园**锚点为 `[120.3997982, 31.0810719]`，OSM `way/1332791315` 是园区面，只作为位置与场地依据。[苏州市园林和绿化管理局的园林历史](https://ylj.suzhou.gov.cn/szsylj/ylls/wztt.shtml)支持坐西朝东、前中后楼与厢楼相接、北园池石回廊曲桥的空间语汇。片区有 10 个建筑设施项与 3 组叠石，包含三进楼厅、双层跑马廊和小北园；楼间距、池形与细部为形制综合。详见 [宅园数据](data/districts/chunzailou-garden.json)与[布局图](data/districts/chunzailou-garden-design-plan.png)。[苏州地方志](https://dfzb.suzhou.gov.cn/dfzb/szdq/201905/4169ddc4eb2c49f18279bd6bca53351f.shtml)和[市政府地名保护名录](https://www.suzhou.gov.cn/szsrmzf/zfwj/201901/KQ6BCKNZPM1454M1QH250VZXQZUEJC9W.shtml)提供身份依据。

两个设施内容区均保留源锚点、源 ID 和设计锚点，并放入全图统一坐标；校园局部布局检查中的非预期主楼相交、道路穿主楼、运动场越界面积均为 0。树位是设计点景。[真实设施工作记录](../work/景观二修_真实设施.md)保留局部数据形成时的证据，当前浏览方式以同一张地图为准。

## 浏览操作

| 操作 | 功能 |
|---|---|
| 上方地点按钮 | 相机前往地图中的陆巷、中学或宅园 |

| 右键或 Shift + 拖动 | 平移 |
