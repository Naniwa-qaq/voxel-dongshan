# 重制版建筑构件实现

日期：2026-10-20。模块：[architecture.js](../东山镇_重制版/js/architecture.js)。

本文件记录已经实现的构件与程序检查，不代替最终场景截图的美术验收。建筑采用东山本地照片支持的白灰墙、黛瓦、石墙脚、木门窗、檐廊与空院关系；尺寸属于综合原型设计，并非单体测绘复原。

## 接口与坐标

```js
const info = DSArchitecture.build(builder, {
  type: 'house', // house | shop | courtyard | modern | pavilion
  width: 10.4, depth: 7.2, floors: 1, seed: 7
});
// builder.box(x, y, z, width, height, depth, colorNumber)
```

`builder.box` 的位置参数为盒中心。y 竖直，房屋地面 y=0，正门朝 +z，屋脊沿 x。模块不引用 THREE 或其他渲染库。全部盒边界先量化到 0.2 米网格；盒中心会因偶数或奇数格宽度落在 0.1 米格，这是边界对齐的自然结果，不表示构件厚度降到了 0.1 米。

返回值包括 `width/depth/height/floors/eaveHeight/grid/type`、`door`、`bounds`、`boxCount`。`bounds` 是实际全部盒子的外接范围，含屋檐、门阶及商铺廊；应据此整平基底与避让树木。`door` 是本地入口位置、门宽与朝向。

普通屋、商铺和现代房的 width/depth 是墙体外尺寸，檐口与踏步会超出。院落的 width/depth 是**整个组合包络**，默认 28×24 米，内部主屋、门厅、可用时的两侧配屋及院墙均在包络内。院落尺寸最小 12×14 米；小于这个值不适合此四部件体系，调用端应选普通屋或放大综合院落空间。亭为四柱和阶梯歇山概括；未使用圆柱、光滑斜面或三角网。

## 已实现构件

- 墙厚 0.4 米，按开口的高程分段分配实墙，门窗位置不存在被黑色贴块覆盖的完整墙。门窗板退到墙体内部，外层框、格栅与深层横档分别成形。
- 普通单层檐高 3.8 米，双层 7.0 米，层高以 3.2 米递增。石基、门槛与两级踏步衔接地面；灰墙、背立面与两侧山面都有完整开口或构件。
- 屋面采用 0.2 米逐层升高的两侧瓦条构造，保持屋顶内部空间，山墙以同层级的白色阶梯封口；外伸檐口、暗色檐板、逐根短椽、正脊与低矮脊端分别建模。
- 瓦条以低饱和灰青色为主体，局部灰阶变化，0.8 米间隔的细瓦垄沿坡逐层连续。该节奏属于体素表达，没有把瓦垄厚度当作真实小瓦测量值。
- 商铺增加前部通透木廊、柱脚、柱、梁和四层小披檐，门面退入。没有批量添加红柱、金饰、灯笼或招牌。
- 院落有实际空院、板石铺地、四周院墙与街侧留空的门口。侧配屋只在空间足够时放入，避免挤满小院。四栋院落复用相同完整民居精度，不用简化盒子代替配屋。
- 现代屋采用平顶、四边女儿墙与压顶，保留与古式屋同精度的真窗洞和门洞，没有套用古屋双坡顶。

## 程序验证结果

`node --check 东山镇_重制版/js/architecture.js` 通过。对默认 5 种类型、14×9.2 米双层屋、16×18 与 12×14 米院落逐盒检查：坐标均为有限数，三个尺度均至少 0.2 米，全部最小与最大边界均对齐 0.2 米。

| 原型 | 默认盒数 | 实际包络（米） |
|---|---:|---|
| 10.4×7.2 单层普通屋 | 804 | x ±5.6，z -4.2 至 4.8，高 6.6 |
| 10.4×7.2 两层商铺 | 936 | x ±5.6，z -4.2 至 5.4，高 9.8 |
| 28×24 四栋院落组合 | 3220 | x ±13.8，z -11.8 至 12，高 6.4 |
| 12×8.4 两层现代屋 | 241 | x ±6.2，z -4.4 至 5.4，高 7.8 |
| 6.4×6.4 四柱亭 | 275 | x、z ±3.2，高 5.8 |

数量是整个成品构件组的盒子数。现代屋无分层坡顶，因此盒数少于古式屋；院落总数包含多栋完整建筑，不能和一栋屋直接比较。

默认前门的体积探针：x=0.4、y=1.2 时，z=3.5（外墙面向内 0.1 米）处为空；z=3.3（向内 0.3 米）才接触深色门板。该检查确认凹洞存在，但深度在画面中的可读性仍须由约 15–30 米斜视机位检验。

## 集成时的质量检查

1. 一次整体旋转完整建筑，不做非等比缩放。地面基础整平应覆盖实际 bounds，台阶最低点 y=0。
2. 合批不得跨洞口补面。可以删除实体内部遮蔽面，但不能合并门窗孔洞、瓦条台阶或檐底空区。
3. 近景检查正面、背面、山面、檐底和院内，特别检查朝向变化后的洞口遮挡、树枝穿檐与相邻屋顶重叠。
4. 屋顶需在白昼低雾下可分辨层边、瓦垄和脊线。不要为制造戏剧性把屋面压到统一近黑。
5. 这是对本地传统形态的完整类型化构件，并未声称精确复原惠和堂、某一座民居或某个学校。
