# 重规划：屋舍与植被美术标准

日期：2026-10-20。状态：仅规划，未生成模型、代码或新图片。

**所有入选屋舍采用同一构件精度下限，达到《云山巨城》近景可辨屋顶与门窗的程度。普通民居与地标在体量、构件种类和装饰数量上有区别，不能在建模精度上分成高低档。**房屋可少选、重复对象可综合；每个留下的房屋都必须有完整的近景表现。本重规划进一步采纳真门窗凹槽与分枝透空作为工艺目标；它们是对用户质量要求的具体设计落实，不是用户逐项提出的原文，也不声称原作全部实现。

本标准中的 0.2 米指参考原作的建模网格；机位、像素阈值及树冠尺寸均为待试做验证的美术设计建议，不代表东山建筑、植物的实测尺寸或数据定位精度。

## 2. 全场景的形体约束

- 建筑、台基、挡墙、踏步和植被均使用清楚的盒面、层叠与阶梯轮廓。连续斜瓦坡、TIN 山坡、三角切面岩坡、低面球冠和锥体树均不进入最终风格。
- 地形内部采用何种数据结构由总架构另定；可见地表必须呈台阶式体素表面。屋基落在可读的平整台面或石基上，坡地接地以阶梯、挡墙解决，不能用斜三角裙边或任意高柱把房屋架起。
- 房屋本地构件采用统一 0.2 米网格。墙面可以合并为长盒、共面方格可以合并提交；合并后必须保留可见轮廓、厚度、接缝与开口。建模网格与地理底图分辨率分别记录。
- 所有已选房屋和树木均应可被相机接近。远景减少不可分辨细节的绘制时，完整模型仍须存在，接近后恢复相同标准；不能给普通屋永久保存一个低精度版本。

## 3. 每个入选屋舍的构件下限

下表是每屋验收项。构件样式由对象资料决定；即使只有朴素直檐、普通山墙，也应具有相同网格与几何深度。

| 项目 | 必须形成的几何与观看效果 | 不通过的表现 |
|---|---|---|
| 屋顶层叠 | 坡向由连续水平薄层逐级缩进构成；近景能分清层边，脊线与檐边连续，屋顶有实际厚度 | 一个光滑斜坡、一个三角屋盖；只贴条纹；层边互穿、漏光 |
| 正脊与收边 | 正脊作为独立实体高于两坡相接位置；两端及山墙交接有完整收口；是否有脊饰由证据决定 | 仅把整屋顶颜色涂深；所有房屋都加夸张吻兽或翘脊 |
| 檐口与檐下 | 出檐与墙有可读水平距离；檐板厚度、暗色底面、必要的椽/檩节奏形成真实遮蔽 | 无厚度薄片；檐下与外墙同亮；墙顶穿出屋面 |
| 墙厚与墙脚 | 外墙在门窗洞、转角和院墙端部能看到厚度；墙脚/石基与墙面有实体分层 | 实心大盒外贴黑门窗；无厚度卡片墙；墙身悬空或埋入坡面 |
| 真门窗凹槽 | 墙体在开口处让出空间，具有门楣、两侧洞口和窗台/门槛；窗框或闭合门扇位于洞口内部。斜看有遮挡与进深，转动机位能看见洞侧 | 用贴花、深色平面或发光块覆盖完整前墙；阴影纹理伪造开洞 |
| 门窗细部 | 开间节奏、门扇/窗框/格栅至少有两级实体层次；只在资料支持处使用花格、门罩等类型 | 所有窗同一亮方格；每栋无依据添加相同雕花门罩 |
| 山墙 | 山墙与屋坡关系完整，厚度与压顶可见；普通平直山墙、封火山墙等按对象证据选用 | 把原作马头墙机械复制到所有东山屋舍；只有正面，背侧与山面缺构件 |
| 台基与踏步 | 入口和地面能连续衔接；基座、门槛及台阶按同网格形成层次，石墙或墙基有适度明暗区别 | 只抬高房屋；整村统一高台；踏步过陡或入口无通路 |
| 院落与围合 | 入选院落应保留真实空区；主屋、配屋、廊、院墙分开形成体量，开口连接街巷。资料不足时明确采用概括院落，不假称完整复原 | 用屋顶覆盖天井；把院落填满；以同一排盒子冒充多进宅园 |
| 四面完成度 | 正、背、山面、屋顶及可见院内立面均有收口，任何允许到达的近景方向均不暴露半成品 | 为一个主镜头制作完整正面，其余立面永久降档 |

原作可迁移的尺度例子包括：0.2 米屋顶层高/檐板厚度、普通民居 0.6 米墙基、3.8/6.4 米单/双层墙高，门罩等构件再以 0.2 米递进（L990–1002、1143–1172）。这些是原作程序的比例，不是东山的营造尺度。新模型须保持“门窗—层高—屋顶—树冠—街巷”的整体关系；已有照片不能给出精确尺寸时，参数标为美术概括。

真凹槽可先以 1–2 格的进深作为试模起点，封闭门扇可以留在洞内；不要求每屋开放室内。0.2 米网格也不意味着要把现实中所有细小木线、瓦当、雕刻放大到一格。不能表达的微小雕饰可通过简洁分层概括，门洞、屋脊、檐口等识别结构必须保留。

## 5. 树木与茶果意向的形体标准

### 5.1 所有乔木的共同下限

- **主干可追踪：**从根部/地面延伸到冠内，截面有粗细变化，转折由短盒阶梯连接，不能仅在大冠下插一根短棒。
- **分枝实际承托叶簇：**以主干—一级枝—必要的二级枝组织冠形。近景能看出枝条从何处分出、连向哪些叶簇，禁止悬空叶球、互不相接的随机树枝。
- **叶簇有大小层级：**先建立偏心、错层的大簇，再用较小盒簇塑造外缘与局部缺口。细盒应形成自然延展的组群，不能把整冠替换成一只八面体、二十面体、球体、立方体或完整长方体。
- **冠层保留透空：**斜看能穿过部分枝叶空区，树冠中下部与外缘留有可读间隙；主干和部分分枝不能被同一实心大冠完全包住。透空应来自几何布局，不靠噪声透明纹理随机打洞。
- **轮廓和颜色共同分层：**相邻叶簇使用有限的同色系明暗；顶面、侧面、冠内有区分。颜色噪声不能代替形体，也不把每个细盒涂成独立随机亮绿。

细化可采用“若干主叶簇 + 0.2–0.4 米的小盒修边”的试模方案；大簇约 0.6–1.6 米只是美术起点。叶簇数应由冠幅、分枝和近景读感决定，不能以固定最少盒子数宣称达标。主枝的斜向生长也应由短盒步进表达，避免把光滑斜圆柱塞进统一体素景观。

### 5.2 不同景观意向的差别

| 意向 | 应保留的形体与空间关系 | 资料与标注要求 |
|---|---|---|
| 一般阔叶乔木 | 清楚的干枝与偏心冠幅；多个错层叶簇，局部透空，树冠重量由分枝承托 | 无法识别树种时称“概括阔叶乔木”，不擅自命名为某种本地树 |
| 庭院或路旁树 | 完整近景枝叶；冠缘与屋檐、院墙和通路有明确间距 | 按参考确定位置角色；不从一幅局部照片推定全街树列或逐株位置 |
| 果园意向 | 单株果树有较低分枝、分组冠层与株间空隙；在已确认果园斑块中表现有节律但不机械的种植关系 | 现有官方文字支持东山茶果主题，但没有可定位、可辨冠形的完整样本。未补冠形证据前使用“概括果树”，不凭叶色判枇杷/杨梅/柑橘，不伪造精确树种分布 |
| 茶灌丛或茶垄意向 | 低矮灌丛由许多细盒簇连接成有节奏的冠面；垄端、行间、局部枝茎与地面有分离，近景不成为光滑绿长条 | 茶垄的方向、范围与间距须由资料支持。无地块证据时仅作为明确标注的主题示意，不把山坡统一变成等距茶梯田 |
| 柳、松、竹等特色形体 | 只有入选且有对应参考时再做；例如柳有支承下垂叶带的枝条，竹有成组细秆与分层叶簇 | 原作“临水自动柳、高处自动松、随机花树”的规则是幻想世界规则（L2415–2440），不迁移为东山生态分布事实 |

房树比例应通过同一机位检查。冠幅、主干高度与相邻门窗、檐高共同读到，不能把一个成熟乔木缩成灌木点，也不能把所有果树放大为盖过整栋住宅的巨冠。没有现场尺度时记录设计比例，不能以“真实树高”名义报数。

## 6. 每个对象的参考对照与机位验收

统一基准建议：输出 **1440×1000、像素比 1、垂直视场角 45°** 的截图，近景先用清楚的白昼、低雾环境。所有距离均为试验建议，最终以实际屏幕可读性验收；目标尺寸、朝向、透视缩短会改变像素占比。沿街或临水画面中的 80–150 像素房宽可作为主体识别参照；构件特写另以 350–750 像素房宽验收门洞和薄层细度，不能混用两种标准。

对视野中心、近似垂直视线的尺寸 `s`，估算投影为 `p ≈ 1000 × s / (2 × d × tan(22.5°))`。因此 0.2 米参考段在 25/40/80/120 米处约为 9.7/6.0/3.0/2.0 像素。这是相机几何估算，**不是从原作截图测得的精度指标，也不是东山测绘值**。原型自查已说明，二十余米屋顶只占约 1.5 像素时，任何构件精度都无从展示。

| 对象与机位 | 建议距离/角度 | 应在画面中实际读到的内容 |
|---|---|---|
| 每屋：正面斜视构件特写 | 距主要立面约 15–30 米，眼高约 1.6–2.4 米，水平斜看 30–45°；完整屋宽宜占 350–750 像素 | 门洞进深、洞侧墙厚、门槛、窗框的遮挡关系、檐板底面；0.2 米参照构件在有利方向宜至少 4 像素 |
| 每屋：屋顶斜俯视 | 距主体约 25–50 米，俯角 30–45°；主要屋顶宜占 250–600 像素 | 连续屋面层边、正脊、檐口、山墙与顶的接合；至少数条相邻层边能分别辨认，不能全部糊成一面 |
| 每屋：背面/山面/院内补景 | 依对象包围盒调整，通常约 15–40 米；不得只复制正面机位 | 所有允许近看的立面完成、院落留空、廊与门洞连接、台基接地；被前屋遮住时为该屋另设机位 |
| 每树：正面与侧面轮廓 | 距树约 10–25 米，冠幅宜占 180–400 像素，以天空或安静墙面作背景 | 至少两方向能分清主干、分叉、主要叶簇和冠缘空隙；枝干不是独立悬空色条 |
| 每树：冠下斜视及冠上补景 | 距树约 8–18 米；冠下看分枝，轻俯看冠层层次 | 可见主干延续、枝与叶簇连接；至少两处清楚的叶簇间空区，近景空隙宜达到约 4 像素，避免抗锯齿后全闭合 |
| 每处房树组合：沿街/临水中近景 | 先试距组合约 70–150 米，按实际屋宽与透视调整；至少一栋主体屋宽达到约 80–150 像素 | 房、树、院墙、路面分层；乔木与灌丛比例、巷道通行空间、白墙黛瓦节律仍可辨；此项验主体识别，不验凹槽细度 |
| 同一组：较远景 | 建议先试 150–300 米并记录实际像素，不能默认用全镇全景替代 | 屋顶轮廓、山墙变化、院落空隙与树冠分组连续保留；无跳变成单块屋盖或多面体树的过程 |

以上覆盖每个入选房屋与树木对象。可复用构件库和验收工具，但不能只验一座地标，再默认普通民居通过。每个对象保留：参考图/代码出处、采用的类型、设计尺寸、近景机位、验收截图、缺失证据与是否通过。相同模板的实例也要检查接地、朝向、与邻屋邻树的穿插。

## 7. 通过条件与后续试作顺序

先提出一个普通住宅、一个有院落的住宅、一株阔叶树及一段茶果意向的试作清单；这一顺序用于在扩大数量前验证标准，**不意味着只给试作对象高精度**。本轮不实施试作。

每个对象只有同时满足下列条件才可入选最终场景：

1. 近景能逐项看到上述实体构件，所采用的地方类型与参考一致，未知部分有明确概括记录。
2. 同一精度覆盖普通屋与地标、房屋各可见立面；树的主干、分枝与细叶簇均成立。
3. 中景房树街院关系可读，远景轮廓保持；地表与树冠均无被禁用的斜三角/多面体替代。
4. 对照检查在清楚白昼完成后，再检验晨暮氛围。雾、曝光、材质噪声不能遮住形体缺陷后被判为通过。
5. LOD/合批后重复同机位比较实际图像：构件消失、冠层封死、门洞变贴片或屋顶突变均须退回。面数、批次数和帧率是性能记录，不是美术通过凭据。

普通屋形制样本、茶果冠形及实际分布是当前关键资料缺口。它们应决定哪些类型可以可靠入选；不能再通过铺满通用低精度房树来填补。
