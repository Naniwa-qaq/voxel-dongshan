# 景观二修：建筑形态与设施组件

本次仅修改 `东山镇_重制版/js/architecture.js`，保持 `DSArchitecture.build(builder, spec)` 中心盒输出接口。建筑类型细部按 0.2 m 构件网格重建；尺寸变化重新排列墙段、洞口和瓦层，不对成品作非等比拉伸。

## 对照问题

已查看当前 `qa/house.png` 和用户截图。已有民居的瓦层、窗框等细节可见，但长方体、主脊、双层整排木窗几乎完全一致；把同一资产分散到地形上无法形成街巷的节奏。本次把变化落到平面、屋脊方向、体块高低、前廊、院落留空与开窗逻辑上。大面积定位底色由场景地表逻辑处理，建筑模块仅保留贴合墙脚的基座和门前短台阶。

## 新类型与推荐分配

| type | 推荐宽×深（m） | 形成差异的构造 | 推荐位置 |
|---|---|---|---|
| `narrowHouse` | 6.8–8.4 × 9.2–12.2 | 前山墙窄面深进、纵向主脊、两层主体与低后厨相接，侧面少窗 | 紧凑沿巷地段 |
| `rowHouse` | 10.4–15.6 × 6.2–8.4 | 2/3 个相连开间，各自纵脊与山墙、低矮体量、前后服务门 | 街巷连续界面 |
| `sideCourt` | 11.2–15.6 × 10.0–12.2 | 后主屋与侧配屋组成 L 形，真正留空的侧院、沿街院门、不同屋顶高度 | 宽地块、街巷转折 |
| `workshop` | 10.4–15.6 × 6.2–8.4 | 一层低长瓦顶、多扇木门面、落柱前檐、后服务门，无虚构店名牌匾 | 沿街作坊或朴素小店的类型表达 |
| `villageHouse` | 10.4–14.4 × 8.4–11.2 | 朴素现状两层、疏密不同的金属框窗、浅前廊、不对称低附屋 | 村边较新民居、古村与现状区过渡 |
| `schoolBlock` | 24–32 × 10.4；3 层 | 大窗教室、真正开放外走廊、逐层栏杆、端部双折楼梯与留洞楼板、平顶女儿墙 | 学校组团的教学楼组件 |
| `corridor` | 8–20 × 2.8 | 细柱梁架与开放通行空间；默认灰瓦顶，可 `roof:'flat'` | 园林廊道或学校连廊组件 |

这些类型与原有 `house / shop / modern / courtyard / pavilion` 兼容。建议按街段和地块组织成片分配，不要给每一幢均匀轮换类型，否则仍会产生资产目录式撒点。学校、园林的名称及地理定位由设施组团的来源记录决定，本模块不写入实际机构名称。

## 接口与元数据

```js
const asset = DSArchitecture.build(builder, {
  type: 'sideCourt', width: 12.8, depth: 11.2,
  floors: 1, seed: 11
});
// builder.box(x, y, z, width, height, depth, color)
// asset.bounds / asset.boxCount / asset.tags / asset.door
```

`bounds` 为实际体素构件的包络，包含出檐和局部门阶；屋舍的推荐宽深是设计主体/院落的尺度，放置时须使用 `bounds` 留出檐口间距。`rowHouse` 的总宽会随独立开间按 0.4 m 带宽取整；`workshop` 的前檐比主体前伸。复合类型返回 `parts`，侧院返回真实空院的 `court` 范围。

全部新增类型返回 `tags`，例如 `front-gable / L-plan / multi-door-wood-front / open-gallery`。墙体仅使用三个克制的暖白、灰白、浅土灰色调，屋面继续保持灰黛瓦；当前民房用金属框疏窗表达，与木门窗传统房屋区分。

## 本地检查

- Node 语法检查通过。
- 对全部 12 类型、8 组种子与尺寸组合共 96 次生成检查通过：盒尺寸为正、所有数值有限、顶点边界均落在 0.2 m 网格、元数据与盒计数一致。
- 典型生成量（种子 11；普通类型约 12.8 × 10.4 m 的参数，仅作组件复杂度对比）：`narrowHouse` 1164 盒，`rowHouse` 1506 盒，`sideCourt` 1007 盒，`workshop` 1115 盒，`villageHouse` 1028 盒，`schoolBlock` 约 760 盒，`corridor` 334 盒。实际场景由隐藏面合并模块输出表面，不是每盒一个 draw call。
- 走廊端头使用无封闭山墙的瓦顶，保持通透；教学楼中间楼层在楼梯区留洞，防止楼梯被整层楼板封死。

最终渲染需由场景整合后在街巷、学校和园林视角检验。这里的构造是本地材料启发的类型资产，不将未知现状屋高或学校立面当作实测结果。
