# 体素东山镇

以苏州东山镇为背景的体素地图与地方资料研究项目。当前场景将陆巷街村、东山中学和春在楼宅园放进一张连续地图，并加入山势、路水、建筑、树木与生态地被。

地图以地理源数据为依据，经过制图综合与类型化建模；显示距离、建筑细节和植被分布包含设计推断。源位置、设计位置及待核事项见项目内的地理对照和审计记录。

## 打开场景

克隆或下载完整仓库后，用浏览器打开 [东山镇_重制版/index.html](东山镇_重制版/index.html)，即可离线浏览，无需地图密钥或构建步骤。完整操作见[场景说明](东山镇_重制版/README.md)。

如需通过本地 HTTP 访问，在仓库根目录执行：

```sh
node scripts/serve_remake.cjs
```

然后打开 `http://127.0.0.1:8876/东山镇_重制版/`。

## 大源文件与处理环境

Overture 的 `东山镇_数据/overture/buildings_bbox_2026-09-23.1.geojson` 超过普通 Git 单文件限制，仓库以同名 `.geojson.gz` 无损压缩备份，并保留原始 GeoParquet、GIS工作包、来源清单和校验值。场景直接使用已生成的数据，不依赖解压文件。

需要重建GIS工作包或完整核查源文件时，在仓库根目录执行以下命令恢复；解压脚本仅使用Python标准库：

```sh
python scripts/restore_large_sources.py
```

本地安装的Python依赖、缓存、日志与重复ZIP不纳入Git。地理处理脚本的重运行需要相应的GDAL、NumPy、SciPy等依赖；数据来源及处理记录见[数据说明](东山镇_数据/README.md)。

## 来源与使用

本仓库没有将全部内容统一授予开源许可。OSM、Overture、Copernicus DEM、ESA WorldCover和Three.js分别适用各自的许可与署名要求，详见[数据说明](东山镇_数据/README.md)及[Three.js许可](东山镇_重制版/vendor/THREE-LICENSE.txt)。

地方参考照片、网页存档和学习资料保留原始出处；尚未确认开放复用权的内容用于内部研究。需要公开展示或再分发素材时，应逐项核对其来源和授权。场景中的普通建筑立面、树形及生态布置属于设计表达，不替代实测资料。
