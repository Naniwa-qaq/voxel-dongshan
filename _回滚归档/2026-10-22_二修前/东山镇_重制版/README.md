# 东山 · 山湖之间

重制版先完成一个 **600 × 540 米的陆巷连续样区**，把制作尺度放回每座屋舍、街巷和院落。这里是东山镇还原工作的第一块可近看成果，后续再沿相同标准扩展范围。

双击 [index.html](index.html) 即可离线打开，无需联网、地图密钥或构建工具。[中文阅读版](README.html) 会直接读取 `js/design.js`，显示当前完整房院项数及类型数量；数量随设计数据更新，无需手动同步。一个院落项可以由多栋完整房屋组成。

## 这次改变了什么

沿用《云山巨城》的细网格构造思路：屋舍以 **0.2 米构件网格**重新搭建，逐层瓦顶、正脊、檐板与椽、白灰墙、石墙脚、真正分段让空的门窗洞和内退格栅均有实体深度。普通民居、院落配屋和现代房都能近看；现代房采用平顶与女儿墙。树木由连续干枝和错层、透空的细叶簇构成。

地表、屋舍、树木都以水平顶面、竖直侧面及阶梯轮廓组织，不再使用不规则三角网山坡或多面球树冠。

## 地理数据如何变成设计

**真实源数据 → 非均匀锚点映射 → 完整房院重新构造。**

源数据提供陆巷位置、足迹、路水关系与宏观地势。制图综合先按道路和水道分组，选取有代表性的房院，归并同组重复内容；再对地理锚点和网络做单调的分段距离调整，保留岸线、街坊和山村关系。新增的同组附屋仍沿用完整构件体系。房屋的门窗、层高和 0.2 米网格不随地理范围一起机械缩小。

建筑数量及源—设计关系见 [对照图](data/source-design-comparison.html)、[设计数据](data/design.json) 和 [分组记录](data/cartographic-groups.json)。[运行检查记录](qa/runtime.json) 保存实际加载、对象与截图机位信息。

普通立面、层数、树形及树位属于本地形态支持的类型设计。惠和堂、紫石街、寒山港尚未取得可靠的单体定位，场景没有把这些名字赋给任意房院、街巷或水道。

Copernicus GLO-30 的源 DSM 约为 **30 米**分辨率，用于宏观山势；渲染采用 **1 米显示方格**，村内采用共享阶地和房基衔接。插值加密与制图整地使场景可读、可行走，并未新增实测地形精度。

## 浏览操作

| 操作 | 功能 |
|---|---|
| 左键拖动 | 环视 |
| 右键或 Shift + 拖动 | 平移 |
| 滚轮 | 接近、拉远 |
| 双击屋舍或地面 | 聚焦该位置 |
| WASD / Q、E | 水平移动 / 调整目标高度 |
| 1—6 | 湖岸、街巷、屋舍、院落、树下、总览 |
| H / ↺ 按钮 | 隐藏界面 / 重置当前视角 |
| 日光滑杆 / i 按钮 | 调整晨午暮 / 打开资料说明 |
